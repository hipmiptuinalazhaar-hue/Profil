# Information Architecture

## Primary journeys

### Student / prospective member
Home → Programs → Business or Event → Join HIPMI PT

### Partner / stakeholder
Home → Impact → Programs → Partnership → Contact

### Public / organic search
Search result → Article or Event → Organization → Programs → Ecosystem

## Route map

| Route | Purpose | Phase |
|---|---|---|
| `/` | Brand, trust, ecosystem overview, primary conversion | 1 |
| `/about` | Institutional story and positioning | 2 |
| `/organization` | History, vision, mission, values, structure | 2 |
| `/leadership` | Editorial leadership profiles | 2 |
| `/team` | BPH, heads of divisions, compartment roster | 2 |
| `/programs` | Program portfolio | 3 |
| `/programs/[slug]` | Program detail | 3 |
| `/business` | Member business directory | 4 |
| `/business/[slug]` | Business detail | 4 |
| `/impact` | Verified impact metrics | 4 |
| `/events` | Event discovery and status | 5 |
| `/events/[slug]` | Event detail and registration | 5 |
| `/news` | Official newsroom | 5 |
| `/news/[slug]` | News article | 5 |
| `/insights` | Thought leadership | 5 |
| `/insights/[slug]` | Insight article | 5 |
| `/partnership` | Collaboration pathways | 6 |
| `/media` | Press, assets, publications | 6 |
| `/gallery` | Editorial visual archive | 6 |
| `/join` | Membership journey | 6 |
| `/contact` | Institutional contact | 6 |

## Homepage information hierarchy

Hero → Impact snapshot → About → Featured programs → Entrepreneur ecosystem → Member businesses → Impact → Upcoming event → Latest stories → Partnership → Leadership → Gallery → Join → Footer.

Impact modules remain unpublished until metrics are verified.
