# Phase 3 — Global Shell & Flagship Hero

Status: **complete**

## Delivered

- reusable premium `SiteHeader` and `SiteFooter`
- desktop institutional navigation
- native, keyboard-usable full-screen mobile menu without client JavaScript
- ID/EN shell and hero copy through `?lang=id|en`
- flagship hero based on the approved **Institutional Momentum** direction
- one dominant real documentary photograph, no synthetic imagery and no carousel
- clear hierarchy: institutional label → editorial headline → factual supporting copy → CTA → manifesto
- functional CTA paths: About route and official email join intent
- high-resolution hero media with explicit dimensions and no upscaling
- reduced-motion fallback
- keyboard focus states and skip link
- responsive layout from 320/360px through wide desktop
- production Open Graph/Twitter image bound to the same authentic hero photograph

## Visual implementation constraints

The hero intentionally avoids:
- centered SaaS layout
- card walls
- purple/blue web3 gradients
- glassmorphism stacks
- low-resolution image masking
- auto-rotating media
- decorative 3D objects
- looping motion

## Phase boundary

Phase 3 does not pre-build Phase 4 storytelling, Phase 5 program ecosystem, or Phase 6 leadership experience. The homepage therefore ends after the flagship hero and institutional footer rather than publishing fake or incomplete sections.

Future phases must reuse the shell and design primitives instead of replacing them with a separate visual system.
