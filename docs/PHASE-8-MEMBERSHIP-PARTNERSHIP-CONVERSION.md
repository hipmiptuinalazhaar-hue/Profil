# Phase 8 — Membership, Partnership & Conversion

Status: implemented on `phase-6-9-complete-platform`.

## Goal
Turn institutional trust and program architecture into clear, safe next actions for students and collaborators.

## Delivered
- `/join`: four-step membership journey, information checklist, and official email handoff.
- `/partnerships`: four collaboration tracks, public-status guardrails, proposal checklist, and official email handoff.
- Homepage conversion section separating member and collaborator journeys.
- Header Join CTA now points to the membership journey instead of bypassing context.
- Footer exposes both membership and collaboration routes.

## Privacy posture
No public application or partnership form stores personal data on the website. Current conversion flows use `mailto:` links with prepared templates, so no database collection is introduced without a reviewed backend and privacy flow.

## Partnership language
Networking, meetings, event support, sponsorship, and formal partnership remain distinct relationship states. The website must describe each according to actual evidence.
