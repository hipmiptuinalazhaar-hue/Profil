# Asset pipeline

Source photography and official logos are intentionally not committed during Phase 0.

Rules for the next phase:
- preserve faces, clothing, proportions, and documentary truth;
- remove portrait backgrounds only after explicit approval;
- keep original masters outside optimized derivatives;
- generate AVIF/WebP derivatives for web delivery;
- use descriptive, stable filenames and meaningful alt text;
- never publish an affiliation/partner logo without an accurate relationship label.
